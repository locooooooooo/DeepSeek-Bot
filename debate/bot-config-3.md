# 辩论赛辩题模板《短剧工厂》（第三期 · 刺激赛场版）

配套辩论中心的「辩题库」。节目名《算力的去处》。一份模板 = 模板名 + 规则 + 8 张成员卡。每张卡自包含（通用约定已展开），逐块整段粘贴即可。

与前两期的差别（来自本期提示词包：90 秒、正反各 2 人、短视频口播节奏）：

- 四名辩手：正方一辩（开场+立论）、反方一辩（开场+立论）、正方二辩（互攻+收束）、反方二辩（互攻+收束）。由现役成员换装：正方辩手→正方一辩、反方辩手→反方一辩、事实核查官→正方二辩、逻辑评委→反方二辩。名字和角色标签随模板一起换，下一场换个模板再换回来。
- 本场没有核查环节（提示词包里没有核查官），事实核查官本场改任正方二辩。
- 评分改为两票快评：实证评委、观众评委各一票，1:1 时主持人投决定票。
- 全场不和解：收束之后没有总结环节，结果帖只报票数和最佳金句。
- 结果行以「S9 评分结果：」开头——这是系统归档、写记忆的固定标记（`debate.js` 的 `resultOf` 认 `S9|评分结果|获胜`），不能省。

## 用法

1. 用 `node debate/run-match-3.mjs mint` 生成 `template-mint-3.json`（从本文档抽取卡片）。
2. `node debate/run-match-3.mjs start`：铸会话 cookie → 存模板「短剧工厂」→ 直接开赛（第 6 场）。也可以只 `push` 存模板，然后到设置 → 辩论赛里手动选它开赛。
3. 比赛内容都在群「辩论赛直播间」；主持人私聊里是调度过程。

## 一、本场规则（贴进模板的规则栏）

```text
辩题：AI 算力被大量用于生产自媒体和短剧，是生产力的解放，还是内容垃圾的工业化？
正方（生产力解放）vs 反方（内容垃圾的工业化）
判断标准：算力大量涌向自媒体与短剧，整体净效应更接近"生产力的解放"则正方胜，更接近"内容垃圾的工业化"则反方胜；评委评交锋与论证，不评立场对错。
流程：开场对撞（正方一辩、反方一辩各一句）→ 立论（正方一辩、反方一辩各一段）→ 互攻一（正方二辩、反方二辩各一击）→ 互攻二（正方二辩、反方二辩再各一击）→ 金句收束（正方二辩、反方二辩各一句）→ 快评（实证评委、观众评委各一票，平票时主持人决定票）→ 宣布结果。
规则：短视频口播风：短句、有冲突、可金句；开场≤40字，立论≤120字，互攻≤60字，收束≤35字；每次发言只说一个点；不和解、不和稀泥，结尾留张力；禁止人身攻击，不贬低具体的创作者或观众；引用数据须带来源，没把握标"（推测）"；评委只在快评阶段私聊投票一次；辩手自己用 post_to_group 把正式发言发到群里。
```
